## 📦 Featured Projects

### DVLD — Driving License Management System

Complete desktop application built with C# and SQL Server.

- 3-Tier Architecture (Presentation / Business / Data Access)
- 50+ Forms, 25+ User Controls
- 30+ SQL Tables with stored procedures
- Event Exposure Pattern, Transactions, custom controls

➡️ [Repository](https://github.com/YounesJY/ProgrammingAdvices-Roadmap)

### StudentAPI — 3-Tier ASP.NET Core Web API

A clean, layered REST API with SQL Server backend.

- 4 projects: API, Business Layer, Data Access Layer, Contracts
- Request/Response DTOs with DataAnnotations validation
- ADO.NET + stored procedures
- Full CRUD with proper status codes (200, 201, 204, 400, 404)
- Swagger/OpenAPI documentation

➡️ [Repository](https://github.com/YounesJY/StudentAPIProject)

### Win32 API Demos — C# + P/Invoke

12 standalone demos exploring native Windows APIs from managed code.

- Wallpaper, screen resolution, battery, shutdown, MessageBox, processes
- Audio control via NAudio, WiFi adapter enumeration via Wlanapi
- Office COM interop (Outlook, Word, Excel, PowerPoint)

➡️ [Repository](https://github.com/YounesJY/Win32-Api-Demos)

### Karate Club Management — Java EE

Team project (2 devs). Role-based authentication and CRUD.

- Java EE (Servlets, JSP), Hibernate ORM (OneToMany, ManyToOne), MySQL, Tomcat, Maven
- Servlet as single entry point, POST-redirect-GET pattern
- Custom exception-based validation layer
